# 进行中的执行计划

本目录存放正在推进中的执行计划。

## 用途

- 为多文件变更提供上下文
- 记录执行步骤、阶段状态和关键决策
- 让开发者与智能体在不依赖聊天历史的前提下继续推进工作

## 建议命名

建议使用：

`YYYY-MM-DD-主题.md`

例如：

- `2026-04-11-documentation-system-rebuild.md`
- `2026-04-18-rpc-governance-foundation.md`

## 最小内容建议

每个计划至少包含：

- 目标
- 范围
- 受影响模块
- 风险点
- 执行步骤
- 当前状态
- 决策记录

## 迁移规则

计划完成后，应移入 `../completed/`，并补上结果摘要与完成日期。
