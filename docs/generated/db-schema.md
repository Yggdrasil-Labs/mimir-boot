# 数据模型与数据库结构说明

本文件属于“生成类文档”的占位版本。

## 当前状态

Mimir Boot 当前是基础框架仓库，而不是承载单一业务数据库的应用仓库，因此不存在一份稳定、统一的业务数据库 schema 可直接导出。

## 已知事实

- `mimir-boot-starter-mybatis` 提供 MyBatis-Plus 增强能力
- `mimir-boot-starter-mybatis-processor` 提供编译期 Mapper 生成能力
- 仓库重点在“持久层基础设施能力”，而不是某个具体业务库表定义

## 后续建议

如果未来需要增强本文件，推荐从以下方向选择其一：

1. 导出 starter 所依赖的示例表结构与字段约定
2. 生成实体审计字段、分页字段、加解密字段的规范说明
3. 汇总 processor 生成规则，而不是伪造不存在的业务库表

## 维护原则

- 不要在这里手写虚构的业务表结构
- 只有当仓库中存在稳定事实来源时，才扩展为半自动生成文档
