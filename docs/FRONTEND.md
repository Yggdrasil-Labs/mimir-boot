# 前端约束

Mimir Boot 不是前端应用仓库，但仓库级规则仍需要说明，以免智能体在涉及前端时做出错误假设。

## 1. 当前事实

- 本仓库核心是 Java 基础框架
- 不包含独立的 Vue 前端应用
- 前端相关内容仅作为“接入方可能遵循的约束”出现

## 2. 默认规则

- 不要在本仓库主动引入前端框架或前端构建体系
- 不要在无用户明确要求时设计新的 UI/UX 流程
- 如果用户提到接入方前端规则，可将其作为产品约束文档记录，而不是本仓库实现目标

## 3. 若未来出现前端相关能力

只有在明确需求下，才考虑：

- API 文档展示层
- 管理后台脚手架支持
- 前端 SDK / 类型生成

这些能力也应首先明确它们是：

- 本仓库内的正式模块
- 还是只在文档中说明的外围能力
